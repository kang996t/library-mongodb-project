## Q1 类别与价格区间组合筛选

**业务要求：** 查询计算机类中价格为 50—100 元的图书。

**查询命令：**

```javascript
db.books.find(
  {
    category: "计算机",
    price: { $gte: 50, $lte: 100 }
  },
  {
    _id: 0,
    isbn: 1,
    title: 1,
    category: 1,
    price: 1
  }
).sort({ price: 1 })
```

## Q2 标签多选匹配

**业务要求：** 查询同时具有“编程”和“入门”两个标签的图书。

**查询命令：**

```javascript
db.books.find(
  {
    tags: { $all: ["编程", "入门"] }
  },
  {
    _id: 0,
    isbn: 1,
    title: 1,
    tags: 1
  }
)
```

**结果条数：1**

**查询结果：**

```text
[{'isbn': '9787115428028', 'title': 'Python编程：从入门到实践', 'tags': ['编程', '入门', 'Python']}]
```

## Q3 书名模糊检索

**业务要求：** 采用正则表达式查询书名中包含“Python”的图书。

**查询命令：**

```javascript
db.books.find(
  {
    title: { $regex: "Python", $options: "i" }
  },
  {
    _id: 0,
    isbn: 1,
    title: 1,
    author: 1
  }
)
```

**结果条数：2**

**查询结果：**

```text
[{'isbn': '9787115428028', 'title': 'Python编程：从入门到实践', 'author': '埃里克·马瑟斯'},
 {'isbn': '9787115428004', 'title': 'Python数据分析', 'author': 'Wes McKinney'}]
```

## Q4 出版年份范围检索

**业务要求：** 查询出版年份位于 2021—2023 年的图书。

**查询命令：**

```javascript
db.books.find(
  {
    publish_date: {
      $gte: ISODate("2020-12-31T16:00:00Z"),
      $lt: ISODate("2023-12-31T16:00:00Z")

    _id: 0,
    isbn: 1,
```
