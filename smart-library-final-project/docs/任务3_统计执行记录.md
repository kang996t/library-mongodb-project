## S1 图书分类统计

**统计要求：** 按类别统计藏书量、平均价格和平均评分。

**聚合管道：**

```javascript
db.books.aggregate([
  {
    $group: {
      _id: "$category",
      book_count: { $sum: 1 },
      avg_price: { $avg: "$price" },
      avg_rating: { $avg: "$rating" }
    }
  },
  {
    $project: {
      _id: 0,
      category: "$_id",
      book_count: 1,
      avg_price: { $round: ["$avg_price", 2] },
      avg_rating: { $round: ["$avg_rating", 2] }
    }
  },
  { $sort: { category: 1 } }
])
```

## S2 学院借阅量排行

**统计要求：** 关联 readers 集合，统计各学院借阅总量并取前 5 名。

**聚合管道：**

```javascript
db.borrow_logs.aggregate([
  {
    $lookup: {
      from: "readers",
      localField: "reader_card",
      foreignField: "card_no",
      as: "reader"
    }
  },
  { $unwind: "$reader" },
  {
    $group: {
      _id: "$reader.college",
      borrow_count: { $sum: 1 }
    }
  },
  { $sort: { borrow_count: -1, _id: 1 } },
  { $limit: 5 },
  {
    $project: {
      _id: 0,
      college: "$_id",
      borrow_count: 1
    }
  }
])
```

**统计结果：**

    $group: {
      _id: {
        $dateToString: {

## S4 热门图书 Top 10

**统计要求：** 根据借阅流水统计借阅次数最多的 10 本图书，并关联馆藏位置。

**聚合管道：**

```javascript
db.borrow_logs.aggregate([
  {
    $group: {
      _id: "$book_isbn",
      borrow_count: { $sum: 1 }
    }
  },
  { $sort: { borrow_count: -1, _id: 1 } },
  { $limit: 10 },
  {
    $lookup: {
      from: "books",
      localField: "_id",
      foreignField: "isbn",
      as: "book"
    }
  },
  { $unwind: "$book" },
  {
    $project: {
      _id: 0,
      isbn: "$_id",
      title: "$book.title",
      borrow_count: 1,
      location: "$book.location"
    }
  }
])
```
