# 任务三：索引清单与执行计划对比

本实验分别在目标索引建立前后执行相同查询，记录执行阶段、耗时、扫描文档数、扫描索引键数及返回记录数。

## I1 类别与价格复合查询

**查询条件：**

```javascript
db.books.find({
  category: "计算机",
  price: { $gte: 50, $lte: 100 }
})
```

### 建立索引前

```text
{'stages': ['PROJECTION_SIMPLE', 'COLLSCAN'],
 'executionTimeMillis': 0,
 'nReturned': 8,
 'totalDocsExamined': 50,
 'totalKeysExamined': 0}
```

### 建立索引后

```text
{'stages': ['PROJECTION_SIMPLE', 'FETCH', 'IXSCAN'],
 'executionTimeMillis': 0,
 'nReturned': 8,
 'totalDocsExamined': 8,
 'totalKeysExamined': 8}
```

## I2 读者借阅记录查询

**查询条件：**

```javascript
db.borrow_logs.find({
  reader_card: "R20240001"
}).sort({
  borrow_date: -1
}).limit(20)
```

### 建立索引前

```text
{'stages': ['PROJECTION_SIMPLE', 'SORT', 'COLLSCAN'],
```
