# MongoDB 实验配置说明

本目录从成员 A 的 CentOS 虚拟机实际配置导出。所有文件为原始实验环境的配置副本，不是通用一键部署模板。

- 单机：27018，`config/standalone/mongod-smart-library.conf`
- 三节点副本集 `libraryRS`：27117、27118、27119；27120 为临时成员管理实验节点。
- 分片集群：`configRS` 27219，`shard1RS` 27211，`shard2RS` 27212，`mongos` 27200。
- 绑定地址：127.0.0.1 和实验虚拟机 192.168.121.134。换机部署时需修改 bindIp 和 mongos 的 configDB 地址。
- 目录：配置中包含原虚拟机的绝对数据目录、日志目录和 keyFile 路径；部署前需创建目录并设置正确权限。
- 安全：本交付不包含任何 keyfile 内容或账号密码。请在目标环境自行安全生成密钥、创建账户，勿提交密钥或 .env。
- 使用方式：先核对 MongoDB 版本、目录、权限和 IP；再按实验步骤分别启动相应实例。不要在已有数据库上直接执行 rs.initiate 或重新分片。
- 这些文件的存在不代表已在其他机器上通过端到端重部署测试。
