图书情报检索与统计平台

《NoSQL数据库技术与应用（第2版）》· 第3章 MongoDB基础操作 · 实训项目

你将完成一个图书情报系统的完整建设：从数据库部署、数据建模、检索功能、统计报表，到应用程序开发与成果验收。 六个任务按顺序推进，每个任务的结果是下一个任务的输入。

项目说明

业务需求

某高校图书馆拟建设「图书情报检索与统计平台」，用于管理馆藏图书与读者借阅记录，并提供多维度检索与统计服务。

编号功能技术要求阶段
F1部署数据库服务器端口 27017，数据目录自定义一
F2存储图书信息含ISBN、书名、作者、出版社、类别、价格、库存、评分、入库时间、标签数组二
F3存储读者信息含借阅证号、姓名、学院、邮箱、电话、借阅等级、注册时间二
F4记录借阅流水图书、读者、借阅/归还日期、状态，以时间序列集合存储二
F5精确与范围检索按书名、作者、ISBN 查找；按价格、评分、库存范围查找三
F6组合条件检索多条件组合、标签多选匹配、模糊匹配、字段存在性判断三
F7排序与分页按指定字段排序、取前N 条、字段投影三
F8分类统计报表按类别分组统计数量、平均评分、最高/最低库存四
F9热门图书排行按借阅次数降序取前 N 本四
F10借阅趋势分析按年份/月份分组统计借阅量，格式化日期输出四
F11多集合联合分析关联读者与借阅流水，产出活跃读者榜单四
F12统计结果落库将统计结果写入独立集合四
F13建立查询索引为高频查询字段建立单键、复合、多键索引四
F14用户与权限管理创建只读账号与读写账号，验证未授权访问被拒四
F15开发应用程序用 PyMongo 实现菜单式命令行程序五
F16图形化验收用 Compass 完成数据核对、结果验证与数据导出六

数据模型

项目使用四个集合，字段定义如下。你需要按此结构建库并录入配套数据集。

集合 books（图书信息）

字段类型说明
_idObjectId / String系统自动生成
isbnStringISBN-13，唯一标识
titleString书名
authorString作者
publisherString出版社
categoryString类别，枚举值
priceDouble定价（元）
stockInt库存数量
ratingDouble读者综合评分 0—5
tagsArray<String>标签数组
publish_dateDate出版日期
borrow_countInt累计借阅次数

集合 readers（读者信息）

字段类型说明
card_noString借阅证号
nameString姓名
collegeString所在学院
emailString / null邮箱
phoneString联系电话
levelString借阅等级：普通/高级/教师
register_dateDate注册时间
fav_categoriesArray<String>偏好类别

集合 borrow_logs（借阅流水）

字段类型说明
borrow_dateDate借阅时间
return_dateDate归还时间
reader_cardString借阅证号，关联 readers
book_isbnString图书 ISBN，关联 books
statusString状态：借出/已归还/逾期

集合 category_stats（统计结果）

用于承载任务四中输出的分类统计结果，字段由统计管道决定（_id 为类别，其余为聚合值）。
